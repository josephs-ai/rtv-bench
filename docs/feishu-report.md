## 二、测试思路(方法论)

### 2.1 双镜头(Lens)原则 — 区分"产品"和"模型"
- **Lens P(产品视角)**:走厂商官方 API,回答"客户实际能拿到什么"。
- **Lens M(平台视角)**:走 Reactor 统一平台,基础设施一致,只比模型。
- **硬规则:两个镜头的数字永远不进同一张表**(代码层面强制,混用直接报错)。

### 2.2 时延不是一个指标,是三个(按类别定义不同)
| 类别 | 测的是什么 | 主要仪器 |
|---|---|---|
| V2V | 你动一下 → 屏幕里的"你"跟着动(动作-上屏延迟) | 光脉冲互相关(闪光打点) |
| 生成 | 发出指令 → 画面首次可见地改变 | 基线偏离检测 |
| 数字人 | 音频起始 → 嘴唇开始动 | 音视频起始配对 |

关注的是**生成过程中的持续延迟**(你和画面里角色之间的滞后),而非"多久开始出画面"(TTFF 单独记录,不进主指标)。另有 **延迟漂移**指标:角色是否越来越落后(ms/分钟)。

### 2.3 三层评分体系(互不污染)
1. **计算指标**(100% 覆盖):LPIPS 时序闪烁、光流误差、ArcFace 身份漂移斜率、CLIP 契合度、SyncNet 口型;一律以"锚点相对位置"计分(原片锚点 + 真人实拍锚点),不用论文绝对阈值。
2. **盲评人评**(分层抽样):去品牌、统一分辨率转码、乱序、左右随机(独立随机流+记录,可事后检左右偏好)、双画面**同步播放**单一进度条、隐藏重复片段测评委自身一致性;Krippendorff's α 门槛(<0.67 = 有争议,**代码禁止输出排名**)。
3. **可靠性**(独立于质量):S/D/F/T/R/E 六分类,Wilson 95% 置信区间,区间不重叠才允许说"谁更可靠";**"多久崩"用生存曲线**(Kaplan-Meier,活到上限的场次算"至少活了X秒",不丢弃)。

### 2.4 公平性控制(全部代码强制,不靠自觉)
- 预注册评分表:维度、权重、锚点描述先冻结、有日期,改动必须走修订记录(否则 CI 挂)。
- 同一母片 → 确定性降采样(内容寻址 recipe_id,逐 run 记录),禁止放大。
- 三种使用场景权重(直播/离线/交互)**全部计算并公布**,排名翻转本身就是结论。
- 交互契约分组:文本驱动 vs 键鼠驱动的产品**不互相排名**(LingBot 实测支持文本指令,与 Happy Oyster 同组)。
- 版本钉死:逐 run 记录服务端版本(已实际捕获到 Reactor 中途升级一次,数据按版本分段)。
- 网络与环境守卫:每轮前后测网络指纹,VPN 切换/漂移的 run 判为环境失效(E),不进产品分母。
- 花费控制:先预留后执行的预算闸;账户欠费(402)判 E、快速中止。

### 2.5 运行编成(三个战役)
- **Campaign A 时延**:串行、独占机器、每条件≥30样本。
- **Campaign B 可靠性**:并行、通宵、每产品 N=300(轮次制:所有产品做完第 n 轮才进 n+1 轮,中途断掉也是均衡样本)。
- **Campaign C 质量**:近无损采集(FFV1/CRF12 由污染实验决定),供计算指标+盲评。

### 3.2 平台地板(echo 校准,固定网络出口)
- C0(净网络):p50 **1928ms**,95%CI 1894–1961(区间宽仅 66ms);40 次运行 **0 失败**。
- C2(+100ms/1%丢包):p50 1728ms,24 有效运行,真实早死 2 次(8.3%)。
- **重要修正**:echo 是 CPU 管线(软编码),**不能当 GPU 产品的可减基线**(桥接交叉验证否决了减法);现按"独立测量+适用范围"报告。
- 负载相关性:发送端负载不同,地板差约 967ms(CI 分离)→ 减法必须负载匹配。
- 旧的"15–20% 平台故障率"确认为 **VPN 隧道切换污染**,净网络下 80 次 0 失败,平台无罪。
- C1/C3 两点因验证器过严被跳过(已重写为"增量带"校验),补测后得到完整退化曲线。

### 3.3 过程性关键发现(方法论价值)
- **编码器污染实验**:首批生成采集内容退化(全是静止占位画面),判定作废、门禁重新封锁 — 制度按设计工作。
- **Happy Oyster 采集真相**:世界是异步生成的,此前录到的是"生成中"占位画面;录制器已改为**画面动起来才开始录**。
- LingBot 需要种子图(上传→set_image→set_prompt→start),协议已从官方 SDK 提取并修复。
- Reactor 中途升级服务端(版本戳捕获),同条件内实测影响 ≤1 帧(33ms)。
- 中国网络环境:Astrill 全线掉 UDP → 改走 **TURN-TLS/443 TCP 中继**(SDK 只试第一个 TURN 地址的 bug 已绕过),全部 Lens M 流量同一路径,内部可比。
