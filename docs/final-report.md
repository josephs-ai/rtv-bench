# 实时视频 AI 产品横评 — 最终报告

> 2026-08-15 · 数据与代码全量见本仓库（技术细节不在本文重复）
> 评测周期 2026-08-10 ~ 08-15 · 测点：中国大陆住宅网络（新加坡出口，全程固定并记录）

---

## 一、结论（两个赛道，互不可比）

### 赛道 1：实时视频转换（V2V）— Lucy 2.5 vs Xmax X2.0

**综合结论：Lucy 2.5 全面领先；Xmax X2.0 有一项确凿优势（整体风格瞬切）并独占国内直连。**

| 维度 | 结果 |
|---|---|
| 输出质量（64 组同源盲评对比） | **Lucy 64:0**（时间一致性 64-0、结构 60-4、风格贴合 61-0-3、细节 64-0）；已对判分做双向对抗抽验，极端判例均与像素证据吻合 |
| 直播中实时编辑（Campaign D，9 类编辑 × 48 场） | **Lucy 赢 5/6 类**（服装 1.4s / 配饰 1.2s / 背景 / 发型 / 参考图换人 3.4s，全部完整生效且保持）；**Xmax 赢整体风格瞬切**（1.0s vs 4.6s，零误伤、稳定保持）；Xmax 无法做局部小编辑（发型 0 命中、配饰基本失败） |
| 可靠性（各自独立口径，不同路由不并表） | Lucy 原生：N=210，S 36% / D 37% / F 26%（F 高度集中于隧道劣化窗口，356 次网络原因运行已剔除不计）；Xmax 经 Reactor：N=85+（尾部补齐中）S 55% / D 33% / F 12%；Xmax 原生（浏览器口径）：90 场，**每场固定 ~2s 开流冻结** → 68/90 记 D |
| 已证实的产品缺陷 | **Xmax**：开流冻结（~2s，每场）；长时段身份漂移（60-90s 内人脸渐变为他人，盲评与audit双重确认）；局部编辑能力缺失。**Lucy**：发型编辑回融（保持率仅 35%）；偶发单帧结构崩溃（可定位帧号） |
| 延迟 | Xmax 原生风格化 ~983ms（仪器化测量）；连接速度两者 1.9-2.7s（含隧道，不作产品归因） |
| **国内市场准入** | **Lucy 在大陆不可直达**（需稳定 VPN，且对隧道质量极端敏感——本周全部"产品坏了"事件事后均归因网络）；**Xmax 国内直连**，在同期隧道风暴中原生通道零故障。对面向国内用户的产品，这一条压过质量分差 |

### 赛道 2：交互世界生成 — LingBot-World 2 vs Happy Oyster

- **LingBot**：21/21 采集齐全，已完成盲评（E6 提示遵循 / E7 物理 / E8 长时一致）与 10 类 artifact 审计；生成即有 artifact（onset ≈ 0s），长时一致性中等。
- **Happy Oyster**：经官方专用 SDK 接通（connect → createWorld → startTravel，流走第二条 Aliyun RTC 连接）；11/21 采集 + 盲评/审计完成，世界渲染质量观感好；`instruct()` 提供带受理回执的转向通道。剩余 10 场仅受测点浏览器 WebRTC 窗口限制，属样本量问题，不影响结论方向。
- 两模型 vs V2V 赛道**永不并表**——任务不同、量纲不同。

## 三、工程发现（建议直接转给相关团队）

1. **Xmax SDK 两个镜像静默陷阱**：连接时 prompt 必须放 `context.prompt`（顶层被静默忽略→实测成"素通"）；直播中更新恰相反，`session.set({prompt})` 生效而 `{context:{prompt}}` 静默无效。两处均无报错。建议 SDK 校验参数形状。
2. **Happy Oyster 双连接架构**：主会话 track 永远是占位色场（官方确认为预期行为），真实画面在世界创建后的第二条 Aliyun RTC 连接上，仅专用 SDK 处理。文档存在但从 `GET /models`（HO 未列出）无法发现。
3. **计费形态**：Reactor 按会话时长计费，世界生成等待与连接开销占大头；Decart 短会话消耗远超直觉（两次充值均在 ~30 场短会话内耗尽），建议核对是否存在会话底价。

## 四、可信度声明（为什么这些数字站得住）

- **网络归因三层防护**：开跑前吞吐哨兵 hold、槽内漂移/丢包守卫记 E 剔除、事后跨产品相关性仲裁（全部 F→E 改判带证据落盘，共 11 例）。
- **盲评纪律**：LLM 判官全盲 + 隐藏重复自检 + 与人工评分门槛校准；判例经双向对抗抽验（判 Xmax 赢的和判 Lucy 赢的都回看了原始帧）。
- **路由隔离**：Lens P / Lens M 永不同表。
- **全量可复算**：所有结论可由仓库内 append-only journal 重新推导；改判全部留痕。
- 一次公开纠错：曾误报 HO 服务端回归，复查后撤回（根因是我方弱采集闸门放过占位帧）——过程与教训已固化为采集必肉眼抽验等三条规程。
